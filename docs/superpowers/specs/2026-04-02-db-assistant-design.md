# Data Assistant - 数据库 SQL 生成工具

> **设计目标:** 轻量级 Windows 桌面应用，连接 Oracle/MySQL 数据库，读取表结构元数据，通过 AI 生成 SQL 语句

## 技术栈

- **Tauri 2.x** - 桌面应用框架（Rust 后端 + Web 前端）
- **React 18** + **TypeScript** - 前端框架
- **Vite** - 构建工具
- **TailwindCSS** + **shadcn/ui** - UI 组件库
- **Rust** - 后端逻辑（数据库连接、加密、AI 调用）

## 功能模块

### 1. 连接管理

- 添加、编辑、删除数据库连接
- 支持 Oracle (SID/Service Name) 和 MySQL
- 连接信息加密存储（Windows DPAPI）
- 连接测试功能

### 2. 表结构浏览

- 连接后加载所有表（仅元数据，不读取数据）
- 左侧表列表 + 右侧结构详情
- 支持搜索/过滤表
- 多选表作为 AI 上下文
- 显示内容：表名、列名、数据类型、约束（PK/FK/NN/UK 等）

### 3. AI SQL 生成

- 底部输入自然语言查询需求
- 调用 OpenAI Compatible API（支持 DeepSeek、MiniMax、GLM 等）
- 可配置 Base URL 和 API Key
- 选中的表结构作为上下文（system prompt）
- 生成结果展示 + 一键复制

## 数据流

1. 用户添加数据库连接（信息加密存储）
2. 连接成功后，前端请求后端获取表列表
3. 后端查询元数据（仅结构，不含数据）返回
4. 用户选择表，输入自然语言需求
5. 前端将需求 + 选中表结构 发送给后端
6. 后端调用 AI API，携带表结构作为上下文
7. AI 返回 SQL，前端展示 + 提供复制按钮

## 安全约束

- 数据库密码加密存储，不明文保存
- 仅读取表结构，不读取表中数据
- API Key 仅存储不传输给第三方

## 移植性考虑

- Tauri 支持 iOS/Android（后续可扩展）
- 前端使用标准 Web 技术，易于适配移动端
- 后端 Rust 代码可编译为移动端库
